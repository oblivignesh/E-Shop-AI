# Return Windows — v1.4

All monetary amounts are in **Indian Rupees (INR, ₹)**.

## 1. Return window by category
| `order_items.category` | Return window (from delivery) | Restocking fee     |
|------------------------|-------------------------------|--------------------|
| Apparel                | 30 days                       | None               |
| Accessories            | 30 days                       | None               |
| Footwear               | 30 days                       | None               |
| Home                   | 30 days                       | None               |
| Kitchen                | 30 days                       | None               |
| Office                 | 30 days                       | None               |
| Stationery             | 30 days                       | None               |
| Fitness                | 30 days                       | None               |
| Electronics            | 15 days                       | 10% (cap ₹500)     |
| Beauty (unopened)      | 30 days                       | None               |
| Beauty (opened)        | Non-returnable                | —                  |

## 2. Condition requirements
- Items must be returned in original packaging with all included accessories.
- Electronics must include original serial number sticker intact.
- Apparel and Footwear must be unworn, unwashed, with tags attached.

## 3. Interaction with the refund policy
Return-window rules gate **eligibility**; the refund policy governs **amount** and **approval**. Both must pass for a refund to be issued.
